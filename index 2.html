Como primeros temas de indagacion en la clase de Introduccion al HTML 5 y el CSS3, aprendimos lo que es el ¨DOM¨. Primeramente el DOM (Document Model Object/Modelo de Objetos del Documento), es un modelo de documento que se carga en el navegador web y que presenta el documento como un arbol de nodos, en donde cada nodo representa una parte del documento. Esto quiere decir que, el DOM es similar a ver el HTML como un esquema o cuadro sinoptico, en donde la cabeza madre o el HTML van arriba del todo, y posteriormente le siguen otros conceptos casi de forma jerarquica de lo que contendra el documento, como el comando head y body, posteriormente title, h1, h2, entre muchos otros, dependiendo de como nosotros queremos contruir nuestra pagina web.

Despues de una actividad en donde hicimos un ejemplo visual del tema para comprenderlo mejor, proseguimos a llevarlo de alguna forma a la practica por medio de este software ¨Visual Studio Code¨, donde se nos enseño de forma rapida y mas sencilla a ir formando uma pagina web por medio del HTML 5, dandonos introduccion a la funcion de multiples etiquetas.
